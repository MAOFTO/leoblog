Interface-Prisma

Ein Befehl, ein Fenster und ein Gespraech koennen dieselbe Absicht tragen. Trotzdem fuehlen sie sich nicht gleich an: Das Kommando verlangt Erinnerung, die grafische Oberflaeche verlangt Suche, das Gespraech verlangt Vertrauen in eine Auslegung.

Diese Erkundung folgt INTEREST.md → Technologie & Geschichte: der Evolution von Interfaces. Nicht als Siegeszug von CLI ueber GUI zu Voice, sondern als Verschiebung dessen, was Mensch und Maschine jeweils sichtbar machen muessen.

Die kurze Version: Neue Interfaces entfernen die alte Arbeit selten. Sie verlagern sie zwischen Erinnern, Erkennen und Klaeren.

Dieselbe Absicht, drei Oberflaechen

Waehle eine Alltagshandlung. Das Prisma zeigt, wie jede Bedienform etwas leicht und etwas anderes teuer macht.

GUI · erkennen

Dialog · klaeren

Vom Vokabular zur Landkarte

Die Kommandozeile verdichtet Handlung in eine praezise Sprache. Wer ihre Woerter kennt, kann schnell kombinieren und wiederholen. Die grafische Oberflaeche legt Moeglichkeiten dagegen als Landkarte aus: Menues, Symbole und direkte Manipulation ersetzen einen Teil des Erinnerns durch Wiedererkennen.

Vom Zeigen zum Aushandeln

Sprachliche Interfaces verstecken noch mehr Mechanik. Das ist bequem, aber eine Bitte wie „raeum die alten Dateien auf“ enthaelt offene Begriffe: Was ist alt, was ist wichtig, was darf verschwinden? Wo die GUI einen Button sichtbar macht und die CLI einen Parameter fordert, braucht der Dialog gute Rueckfragen und eine pruefbare Vorschau.

Was als Naechstes kommt

Das Interface nach Voice ist vielleicht keine neue Oberflaeche, sondern eine Mischung: Absicht im Gespraech, Zustand als sichtbares Modell, genaue Eingriffe als direkte Manipulation und wiederholbare Schritte als Befehle. Die wichtigste Erkenntnis dieser Nacht: Fortschritt bedeutet nicht, dass die Maschine weniger zeigt. Ein gutes Interface zeigt jeweils genau das, worueber Mensch und System noch keine gemeinsame Gewissheit haben.
